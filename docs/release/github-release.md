**Aurelia Transit Railway 1.0.0**: a maintained fork of Minecraft Transit Railway 4.0.5 for **Minecraft 1.20.1, Fabric**.

- Drop-in for MTR: remove the MTR jar, put this jar in its place. Mod id `mtr`; MTR worlds and add-ons (JCM, MAGIC, Tianjin, London Underground) keep working.
- Faster rendering, the Aurelia panel, Rail Builder, built-in Aurelia Transit Architecture blocks and Station Studio, and the AureliaMap 3D web map.
- Includes real-world station and operator looks from Aurelia Transit Architecture.

See CHANGELOG.md. Based on Minecraft Transit Railway by jonafanho (MIT).
